# Prophet Muhammad ﷺ Knowledge Platform

Source repository for the Prophet Muhammad ﷺ biography and research platform.

This repository is being restored from the latest validated project package. Large acquired book/PDF binaries, runtime caches, databases, and quarantine material are intentionally not stored in GitHub.

## Controlling project instruction

`MASTER-OVERRIDING-SITE-INSTRUCTION.md` is the sole controlling project instruction for the entire website and all related processes. It governs existing and future content, code, ingestion, OCR, extraction, transcription, biographies, stories, resources, media, localization, indexing, publication, automation, security, restoration, and deployment.

If any subordinate policy, workflow-local instruction, script, template, importer, generator, renderer, manifest, cached report, or automation configuration conflicts with it, `MASTER-OVERRIDING-SITE-INSTRUCTION.md` prevails.

Every newly created executable/process file must acknowledge it with:

`GOVERNED_BY: MASTER-OVERRIDING-SITE-INSTRUCTION.md`

Repository enforcement is defined in `PROJECT-PROCESS-GOVERNANCE.md`, checked by `scripts/check_master_governance.py`, and enforced by `.github/workflows/master-governance.yml`.

## Editorial integrity

`EDITORIAL-GENUINE-SOURCE-POLICY.md`, `CONTENT_SOURCE_POLICY.md`, `data/editorial_policy.json`, and other specialized policies are subordinate implementation policies and apply only where compatible with the controlling master instruction.

The non-negotiable rule is: **AI serves the source; it never substitutes for source evidence.** Historical/source truth, provenance, canonical ownership, legal/security requirements, and the public-page rules in the controlling master instruction take priority over quotas or automation speed.
